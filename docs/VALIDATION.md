# Проверка публичной версии

Проверено 17 ноября 2026 года в изолированной Linux-среде. Это результаты локального запуска, а не утверждение о статусе GitHub Actions.

| Проверка | Результат |
|---|---|
| Backend pytest | 292 passed, 5 skipped |
| Frontend / static checks | Vitest: 39 passed. TypeScript/Vite: build passed. Ruff: passed. |
| Публикуемые файлы | Шаблоны секретов, приватные адреса и персональные пути: 0 находок после ручной проверки тестовых значений |

Тесты моделей/внешних артефактов могут пропускаться при отсутствии весов. Веса и реальные видеозаписи не входят в поставку. Новый собственный wire adapter проверен локальными протокольными тестами, не реальным LinQ.

Браузерные E2E локально заблокированы средой: Chromium не может создать системный сокет. Workflow CI включает браузерные проверки в GitHub-hosted runner. Его актуальный результат смотрите во вкладке Actions, отдельно от приведённых локальных чисел. Не все внешние интеграции входят в автоматическую приёмку.

Ранее подготовленная ветка использована как база. Большинство рабочих веток входят в неё по истории; альтернативные расходящиеся ветки не переносились целиком поверх проверенной версии. Публичная история новая; ни один старый приватный коммит не импортируется.
